## Project Description
QuickChat is a console-based Java application that allows a user to register
with a username, password, and South African cell phone number. Once registered,
the user can log in with those credentials.

## Features
- Username validation (must contain an underscore and be ≤ 5 characters)
- Password complexity validation (≥ 8 chars, capital, number, special char)
- SA cell phone number validation (international code +27)
- Registration and login with appropriate success/error messages
- Full unit test coverage using JUnit

## Tools Used
- Java
- Maven
- JUnit 5
- NetBeans
- GitHub

## How to Run
1. Clone the repo
2. Open in NetBeans
3. Run QuickChat.java
4. Enter your details when prompted
